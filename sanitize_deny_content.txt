# FORMAT — one POSIX ERE per line. Blank lines and #-comments are skipped.
#          A malformed pattern BLOCKS the push (fail-closed, ADR-011 A4 §2(a)).
# ESCAPE  — `pragma: allowlist` anywhere on a matching line exempts that line.
# OUTPUT  — matches are reported REDACTED. This file must never be made to print the
#           string it exists to withhold, and neither must a memo about it.

# ---------------------------------------------------------------------------
# ⚠ WHY THIS FILE IS DELIBERATELY NOT YET INSTALLED
# ---------------------------------------------------------------------------
# Pattern 1 below matches this vault's own STATE.md and CHANGELOG.md at HEAD. Installing

# content that ADR-016 D4 rules fix-forward and does NOT rewrite.
#
# That collision has exactly two honest resolutions and one dishonest one:
#   (a) an explicit, recorded allowlist for the already-published files, scoped and dated;
#   (b) ship uninstalled with the reason recorded — this, today;
#   (c) ⛔ weaken the pattern until it passes. NEVER. A gate tuned to report green is the
#       defect this vault has filed under three different names.
#
# (b) is chosen because (a) requires the operator's §7.7 ruling on ADR-016 first, and a
# gate installed ahead of the doctrine it enforces is the enforce-before-ratify interval
# ADR-013 A1 already had to annotate against itself.
#
# ---------------------------------------------------------------------------
# Patterns
# ---------------------------------------------------------------------------

# 1. Mesh/overlay host addresses in the RFC1918 private ranges, with or without a port.
#    ADR-016 D2.1 — service-topology reconnaissance, not a credential. Loopback (127/8)
#    and the unspecified address (0.0.0.0) are deliberately NOT matched: both are generic
#    and disclose no host. 192.0.2.0/24 and 198.51.100.0/24 (RFC5737 documentation ranges)
#    are the correct substitutes when an example address is genuinely needed.
(^|[^0-9.])(10\.[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}|192\.168\.[0-9]{1,3}\.[0-9]{1,3}|172\.(1[6-9]|2[0-9]|3[01])\.[0-9]{1,3}\.[0-9]{1,3})([^0-9.]|$)

# 2. Private-key material. R2 already covers the standard PEM header; this catches the
#    OpenSSH public-key form, which R2 does not, and which names a host in its comment.
(^|[[:space:]])ssh-(rsa|ed25519|dss)[[:space:]]+AAAA[A-Za-z0-9+/]{20,}
