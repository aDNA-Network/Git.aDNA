# 1. Mesh/overlay host addresses in the RFC1918 private ranges, with or without a port.
#    ADR-016 D2.1 — service-topology reconnaissance, not a credential. Loopback (127/8)
#    and the unspecified address (0.0.0.0) are deliberately NOT matched: both are generic
#    and disclose no host. 192.0.2.0/24 and 198.51.100.0/24 (RFC5737 documentation ranges)
#    are the correct substitutes when an example address is genuinely needed.
#
# ⛔ CORRECTED 2026-08-27 (F-P7b-af) — THE GUARDS EXCLUDED `.` AND THE PATTERN WENT BLIND.
#    Both guards were `[^0-9.]`. Excluding an adjacent DIGIT is correct and is the whole
#    point — it stops `<forge-overlay-addr>` matching inside a longer quad that merely
#    contains it (a leading digit). Excluding an adjacent DOT was never needed for that,
#    and it cost real matches in both directions:
#      · leading  — an address PRECEDED by a dot was invisible. ⭐ MEASURED, not supposed:
#        three files in this tree carry the instance host in a `…ly.<addr>` construct and
#        the shipped pattern missed all three. All three are coordination memos, which is
#        exactly the D3 class ("correspondence is the most likely carrier").
#      · trailing — an address at the END OF A PROSE SENTENCE (`…runs at <addr>.`) was
#        invisible, because `.` is not `[^0-9.]` and the address is not at end-of-line.
#
#    ⇒ Guards are now `[^0-9]` / `([^0-9]|$)`. The change can only ADD matches, never remove
#    them, so it moves in the fail-safe direction — the opposite of resolution (c) below.
#    Controls: how/tests/test_sanitize_content_gate.sh, 8 arms (4 must-match incl. both
#    recovered shapes, 4 must-NOT-match incl. the longer-quad, loopback, 0.0.0.0 and RFC5737).
#
#    ⚠ Exposure re-measured at `b6c070c` under the corrected pattern: **75 occurrences over
#    23 files**, where the shipped pattern reported 62/20 and ADR-016 rev 2 §C3 sized the
#    prospective allowlist to 62. The allowlist figure has now moved three times (31 → 62 →
#    75) — which is why ADR-016 rev 3 cites this instrument instead of transcribing a number.
(^|[^0-9])(10\.[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}|192\.168\.[0-9]{1,3}\.[0-9]{1,3}|172\.(1[6-9]|2[0-9]|3[01])\.[0-9]{1,3}\.[0-9]{1,3})([^0-9]|$)

# 2. Private-key material. R2 already covers the standard PEM header; this catches the
#    OpenSSH public-key form, which R2 does not, and which names a host in its comment.
(^|[[:space:]])ssh-(rsa|ed25519|dss)[[:space:]]+AAAA[A-Za-z0-9+/]{20,}
